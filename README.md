# Kings Inn & Suites — private website CONCEPT

This website refines Wren's supplied v3 draft. It is an independent illustrative concept, not the hotel's official website. It is not connected to hotel reservations or hotel contact channels. Keep private for Rose's review and 4 5 clearance. No video is included.

## Open the build

The portable package contains `index.html`, `styles.css`, `script.js`, `assets/`, and `fonts/`. Extract the complete archive together, then open `index.html` in a modern browser. Do not move the HTML away from its asset folders. The package needs no framework or installation. The single-file companion, if supplied, embeds the assets and can be opened directly.

The Manus project is available in this task's Preview for private review. Preview is not publication. There is no public hotel domain deployment.

## What the controls do

The booking bar accepts demonstration dates and room choices, then displays a concept-only notice. It never checks real availability and makes no reservation. Call opens the concept contact information only; no phone number has been invented. The inquiry form sends nothing and does not store entries. Rose's supplied email is displayed for the concept project only. Before/after sliders work with pointer, touch and keyboard. Room image toggles and the mobile menu are local interface demonstrations.
